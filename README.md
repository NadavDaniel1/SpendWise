# SpendWise
As part of the mobile application development course at Afeka College Tel-Aviv, I built this app.
**SpendWise** is android app allows users to track expenses, set budgets, and keep track of their finances through real-time syncing and a simple, intuitive user interface.
ן
## Technologies Used

**Java:** Core development language.

**Android Studio -** Development environment.

**Firebase Realtime Database -** Store and sync transaction data.

**Firebase Authentication -** User sign-in.

**Firebase Storeage For Firebase -** Store transaction icons.

**Glide library -** Efficient image loading.


## Features

- **User Authentication**: Secure sign-up/login with Firebase
  
- **Budget Tracking**: Set and manage budgets
  
- **Expense Management**: Add/view categorized transactions.
  
- **Real-Time Sync**: synchronize transactions and budgets with Firebase in real-time.

## How to Use:

1. Register or log in via email

2. Set your monthly budget

3. Add expenses with category and icon

4. View and manage transaction history

5. Log out when finished
